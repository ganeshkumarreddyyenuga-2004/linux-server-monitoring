# Linux Server Administration and Monitoring Automation

## Project Overview
This project monitors Linux server health and automates routine tasks using Bash scripts.

## Technologies Used
- Linux (Ubuntu)
- Bash Scripting
- Nginx
- Cron
- Git and GitHub

## Features
- Monitor memory and disk usage.
- Generate server health reports.
- Check Nginx service status.
- Detect high disk usage.
- Automate health checks using Cron.

## How to Run

Run the health monitoring script:

```bash
./scripts/health_check.sh
